# 電子婚紗 · 使用與編輯說明

## 一、資料夾在做什麼

```
電子婚紗/
├── 電子婚紗.html      ← 【雙擊這個打開】用瀏覽器看相簿
├── 照片/              ← 原始大圖（母帶，不要動它）
├── 相片_網頁用/       ← 自動壓縮過的網頁用圖（網頁實際讀這裡）
├── 音樂/              ← 背景音樂放這裡
├── 設定/
│   ├── 相簿設定.js    ← ★ 你要改內容，只要改這一個檔 ★
│   └── 編輯說明.md    ← 就是本檔
├── 網頁素材/
│   ├── style.css      ← 配色與版面（進階微調用）
│   └── book.js        ← 翻頁程式（不用動）
└── 工具/
    ├── 重新產生相片.py ← 加了新照片時用來壓縮
    └── 挑片預覽/       ← 全部照片的縮圖總覽，挑片用
```

原則只有一句：**大圖放「照片」，網頁用圖在「相片_網頁用」，文字都在「相簿設定.js」。**

---

## 二、最常做的三件事

### 1. 改文字（標題、章節名、照片旁的小字）

用記事本或 VS Code 打開 `設定/相簿設定.js`，改引號 `" "` 中間的字，存檔，
回瀏覽器按 **F5** 重新整理就看得到。

> 注意：不要刪掉引號、逗號、大括號。中文標點沒關係，寫在引號裡就好。

### 2. 換照片 / 調順序

在 `相簿設定.js` 裡面，每一頁長這樣：

```js
{ 型: "滿版", 圖: "DSC00560.jpg", 說明: "早晨八點，還沒有人來" },
```

- 想換照片 → 把 `圖:` 後面的檔名換掉
- 想調順序 → 把整行剪下、貼到別的位置
- 想刪掉這頁 → 把整行刪掉
- 想新增一頁 → 複製一整行，貼在下面，改檔名

**五種版型可以用：**

| 型 | 效果 | 寫法 |
|---|---|---|
| `滿版` | 一張照片一整頁 | `{ 型:"滿版", 圖:"A.jpg", 說明:"" }` |
| `雙直` | 兩張直式並排 | `{ 型:"雙直", 圖:["A.jpg","B.jpg"], 說明:"" }` |
| `雙橫` | 兩張橫式上下疊 | `{ 型:"雙橫", 圖:["A.jpg","B.jpg"], 說明:"" }` |
| `文字` | 整頁只有一段話 | `{ 型:"文字", 主文:"第一行\n第二行", 署名:"" }` |
| `空白` | 留白，調節奏用 | `{ 型:"空白" }` |

`說明` 留空 `""` 就不會出現小字。文字裡的 `\n` 代表換行。

### 3. 放背景音樂

把 mp3 檔案丟進 **`音樂/`** 資料夾，檔名改成 **`bgm.mp3`** 就好。

如果不想改檔名，就到 `相簿設定.js` 最上面把 `檔名:` 改成你的檔名。
音量在同一段的 `音量:`，`0.35` 大概是三成，可以改 `0` ~ `1`。

**自動播放的設計：** 一打開網頁會先出現封面問候畫面，上面兩顆按鈕
「♪ 開啟音樂並開始」和「靜音瀏覽」，由看的人自己決定。
進去之後右上角隨時可以開關。（瀏覽器本來就禁止未經點擊的自動播放，
這個做法是唯一能穩定播放又不惹人厭的方式。）

## 三、加了新照片怎麼辦

1. 把新照片放進 `照片/`
2. 執行 `工具/重新產生相片.py`（需要電腦有 Python + Pillow）
   - 命令列：`python 工具/重新產生相片.py`
   - 它只會處理還沒壓縮過的新檔案，不會重跑舊的
3. 到 `相簿設定.js` 把新檔名安排進想要的章節

> 沒裝 Python 也沒關係 —— 直接在 Claude 這裡說「我加了新照片，幫我重新產生」，
> 我會直接幫你跑完並更新設定檔。

---

## 四、想改顏色或字體

打開 `網頁素材/style.css`，最上面那一段 `:root{ ... }` 就是全部的顏色與字體，
改那幾個色碼就會整本一起變。

```css
--紙:   #F6F1E9;   /* 頁面米白 */
--墨:   #3B352E;   /* 主要文字 */
--金:   #B08D57;   /* 點綴線條 */
```

## 五、怎麼傳給別人看

- **最簡單**：把整個「電子婚紗」資料夾壓縮成 zip 傳給對方，對方解壓後雙擊 html。
- **想要一條網址**（賓客用手機掃 QR code 就能看）：
  可以放到 GitHub Pages / Netlify / Cloudflare Pages 這類免費空間，
  整包上傳就能用，不需要改任何程式。跟我說一聲我可以帶你做。
